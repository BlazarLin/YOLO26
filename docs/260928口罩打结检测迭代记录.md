## 1. 目标与判定口径

1. 在固定验证集上，NG 图像检出率至少 90%，并优于首版纯 NG 训练模型；同时统计 OK 图像误报率。
2. 每张 NG 只有一个“打结”框。只有预测框与标注框的 IoU ≥ 0.5，且置信度达到阈值，才计为检出。仅图片上出现任意框不算检出。
3. OK 图片只要出现一个达到阈值的“打结”框，即计为该图误报。比较时使用同一阈值、同一 `imgsz`、同一 Python PyTorch 推理分支。默认分支是 one-to-many + NMS；`nms=False` 是独立的 one-to-one 免 NMS 分支，两者阈值不能直接套用。
4. 验证集仅用于选模型、定阈值和分析误检；当前没有第三份独立测试集，因此最终数字是验证集结果，不作为产线泛化保证。

## 3. 官方资料与实验假设

- [Ultralytics YOLO26 训练配方](https://docs.ultralytics.com/guides/yolo26-training-recipe)：少于 1000 图时建议减弱 Mosaic、关闭 MixUp/Copy Paste，必要时使用显式 AdamW 和较低学习率，并考虑冻结 backbone。这里将这些做成受控实验，避免一次改多个因素却无法判断原因。
- [Ultralytics 微调指南](https://docs.ultralytics.com/guides/finetuning-guide)：两阶段冻结/解冻可在小样本下减少预训练特征破坏。是否适合本数据，需以验证集 NG/OK 指标判断。
- [Ultralytics 检测数据格式](https://docs.ultralytics.com/datasets/detect)：无目标的 OK 图允许空标签，本次为其生成空 `.txt`。
- [PyTorch forward hook](https://docs.pytorch.org/docs/stable/generated/torch.nn.Module.html#torch.nn.Module.register_forward_hook)：提取早期卷积、backbone P3/P4 和 neck P3 的激活图。高激活不等同于正确分类，仍需对照标注和预测。
- [YOLO26 免 NMS 检测头说明](https://docs.ultralytics.com/guides/end2end-detection)：默认预测和 `nms=False` 分别走不同检测头；为将来部署，另列免 NMS 结果。
- [Ultralytics 数据增强说明](https://docs.ultralytics.com/guides/yolo-data-augmentation)：HSV 亮度、缩放和平移应按真实产线变化设置；固定机位不宜盲目加大几何增强。本次根据亮度扰动结果测试更强的亮度增强，而不是一次性扩大所有增强。

## 6. 关键层特征可视化方法

用 `python/visualize_knot_features.py` 的 PyTorch forward hook 提取 1 层早期 Conv、4 层 backbone P3、6 层 backbone P4、16 层 neck P3。每层生成各通道绝对激活均值热图和能量最高的 4 个单通道图，对照原图标注框。计算“标注框内平均激活 / 全图平均激活”；这个比值只描述响应强弱，不能证明语义上识别打结。保存于 `x64/output/20260928_084600/features/`，后续对比首版和改进版的相同图片。

特征图输入使用与单张 `model.predict` 相同的最小矩形补边；实际输入为 352×640 而非强行补成 640×640。用 1 张 OK、2 张 NG 逐像素对比了两条预处理路径，结果完全一致；首版、V4、V6、V14 的四张关键图均在修正后重新生成，早期 Conv 的形状为 `[32,88,160]`，backbone P3 为 `[128,44,80]`。此前按方形补边生成的旧热图已被覆盖，不用于结论。

首版四张漏检图的 backbone P3 标注区/全图平均激活比分布在 1.086～1.146；V6 为 1.093～1.164，没有跨越式变化。这与“底层已看到耳带轮廓，后续框范围和检测分数更关键”的逐框分析一致；但平均能量无法分辨哪些通道对打结真正有用，因此只把它当定位线索。

保持首版的基础训练设置，从通用 `yolo26n.pt` 初始化，训练 121 图，验证 34 图。早停于第 37/80 epoch。固定 640 输入、阈值 0.25 下，NG 检出从 B0 的 25/29 降到 22/29，OK 误报保持 0/5；阈值 0.05 时 V1 为 26/29，也低于 B0 的 27/29。逐图对比显示多数失败图仍有 IoU ≥ 0.5 的候选框，但其分类置信度下降。下一轮改为从 B0 权重低学习率继续微调，避免重新学习打结特征。

逐框看 `56s219ms` 更清楚：V6 对耳带下段的局部框为 0.390 分、IoU 0.316，而覆盖完整标注的框只有 0.0098 分、IoU 0.675；V14 的局部框为 0.110 分、IoU 0.283，完整框为 0.0802 分、IoU 0.726。提高框损失并没有消除“局部高分框”，但提高了完整框的置信度和重叠程度。后续应人工统一完整打结范围标注，并补相似贴边形态，而不是简单地把任意局部框算作 NG 检出。

原图逐图分数也解释了阈值边界：V14 的最低 NG 匹配分数为 0.0802，最高 OK 候选分数为 0.0201；阈值 0.07 距最低 NG 只有 0.0102 的余量。V6 除最后一张外的最低 NG 匹配分数为 0.3366，阈值 0.25 有 0.0866 余量。这个余量只描述当前固定验证图，不代表未来批次的分数分布。

V15 在 V14 基础上增强训练亮度变化，原图阈值 0.25 仍为 28/29、OK 0/5；模拟统一加亮 11 后降到 25/29、OK 0/5，不及 V14 在阈值 0.10 的 27/29。按当前结果，继续加大 `hsv_v` 没有形成稳定收益。

V6 在训练侧 105/105 NG 严格检出，匹配分数中位 0.864；验证侧为 28/29，中位 0.776。训练集分数略高，最后一张贴边图是主要尾部风险。训练侧数字只用于观察是否学到样本，不能合并进验证集以抬高检出率。

### 光照批次差异与扰动复测

原图平均灰度：NG 均值约 75.3，范围 68.7～110.0；OK 均值约 64.1，范围 62.1～67.1。两类在这一简单统计上完全分开，验证时 0/5 OK 误报**可能受采集日期/光照差异影响**。这是当前数据最严重的泛化风险之一，不能用训练参数掩盖。

为量化这条捷径，只用训练集均值确定一个 67.935 的灰度阈值：训练 OK 最大 67.139，训练 NG 最小 68.731。这个**没有学习打结形态**的单值规则在验证集也得到 29/29 NG、5/5 OK 正确。结果保存在 `brightness_shortcut_probe.json`。这证明当前验证集可以被拍摄条件区分，因而不能凭它证明模型学会了 OK 与打结的形态边界；需要同光照、同材料批次的两类样本作独立验收。

在固定验证集对全部图片施加同一亮度扰动，V6 默认分支阈值 0.25 的结果如下。这是软件扰动试验，不等同于实际重采样：

追加实验：V10 从 V6 权重继续训练，将 `hsv_v` 提到 0.25。原图 0.25 阈值为 27/29、OK 0/5，略逊于 V6；统一加亮 11 后为 25/29，优于 V6 的 22/29。V10 加平均灰度归一、阈值 0.05 时原图 28/29、0/5；模拟 0.85 倍增益后 27/29、0/5。说明增强可减轻部分光照敏感性，但没有在原图上提高严格检出。V11 在每张图归一到 72 的训练副本上继续微调，在同样归一的原图、阈值 0.10 下只有 26/29、OK 0/5；归一化训练并未带来稳定收益。

### 轻度模糊：定位诊断与验证集选择风险

V6 的目标区域遮挡诊断中，29 张 NG 有 27 张在模糊标注区域后分数下降得多于模糊对照区域；唯一关键漏检 `56s219ms` 反而从 0.0098 升到 0.109。这启发了**整图** 5×5 高斯模糊的诊断，不在验证图上局部处理。V6 + 每图平均灰度归一到 72 + 整图 5×5 模糊，在阈值 0.10 上达到 **29/29 NG、0/5 OK**；均匀亮度 ±11 后相同。模拟 0.85 倍增益后为 28/29、0/5。只做 3×3 模糊仍为 28/29，提示细节抑制强度有影响。

但 5×5 是在当前验证集上观察最后一张漏检后挑出的处理，**不能把 29/29 当独立测试成绩**。在三份按比例随机验证集上，加入“归一 + 5×5 模糊”后，种子 42 和 123 的 0.10 阈值检出保持 34/34、32/34，种子 777 从 33/34 降为 31/34，OK 均 0/5。说明模糊并非稳定增益。当前保守候选仍是 V6 + 640 输入 + 0.25 阈值的 28/29、0/5；归一和轻度模糊作为待独立批次验证的可选方案。

为直接遵循“同一数据集只按训练/验证比例拆分”的要求，另用随机种子 42、123、777 各自生成 75%/25% 的 NG/OK 分层拆分（每份约 100 NG+16 OK 训练，34 NG+5 OK 验证），每份模型都从通用 `yolo26n.pt` 重新训练，未加载首版权重。三份划分同时包含两天图片；结果仅供观察配置对划分的敏感性，**不与保留首版未见图的 B0/V6 表直接横向比较**。

| 随机种子 | 默认分支阈值 0.05 NG 检出 | OK 误报 | 阈值 0.25 NG 检出 |
| ---: | ---: | ---: | ---: |
| 42 | 34/34 | 0/5 | 33/34 |
| 123 | 32/34 | 0/5 | 32/34 |
| 777 | 33/34 | 0/5 | 31/34 |

三份随机验证集在 0.05 下均超过 90%，但图像来自同一批素材，外观相近的图片可能跨训练/验证；这不是独立批次验收。固定首版验证集保留了更难的早期连续图像，适合与旧版权重公平比较。随机划分显示指标可随种子变化，不应以最高的一份做产线承诺。

作为对框损失权重的另一随机拆分复核，在种子 123 的同一 116 训练/39 验证拆分上，均从通用 `yolo26n.pt` 初始化、固定其余配置：权重 10 的 V8 在 0.25 阈值为 32/34 NG、0/5 OK；权重 15 的 V16 为 33/34 NG、0/5 OK，0.05 阈值也由 32/34 提到 33/34。增益只有一张，仍需其他拆分复核。

种子 42 给出反例：框权重 10 的 V8 在阈值 0.25 为 33/34 NG、OK 0/5，权重 15 的 V18 降为 32/34、OK 0/5；阈值 0.05 从 34/34 降为 32/34。三份比例随机拆分中，权重 15 在两份多检 1 张，在一份少检 1～2 张。它可作为贴边框定位的受控实验方向，不能认定为全局更优超参数；当前默认候选保持 V6。

三份验证结果只是重复拆分的敏感性观察，样本彼此重叠，不能当作 102 张独立测试图。若只做描述性合计：阈值 0.25 下框权重 10 为 96/102、权重 15 为 97/102；阈值 0.05 下两者都是 99/102。这个差异不足以支持普遍提高框权重的结论。

同一“训练集定平均灰度阈值”的捷径诊断，在种子 42、123、777 的随机验证集分别也是 39/39、39/39、39/39 正确。这说明随机比例拆分满足本次数据使用要求，却不能消除 NG 与 OK 由不同采集日带来的特征捷径。独立批次验收仍是必要条件。

### 下一批数据与验收建议

1. 同一机位、同一曝光和相近材料批次中同时采 OK 与 NG；每个班次、不同亮度/材料批次各有两类。把采集批次记录在文件名或清单中，避免类别与日期再次绑定。
2. 重点补正常耳带交叉、折转、贴近文字/白色虚线的 OK 难负例，以及上侧短突起和下边界垂带的 NG。训练前人工复核“打结核心”与“尾带/连接段”是否都纳入框，统一标注准则。
3. 形成独立于训练和调参的最终测试集。若要以 95% 置信水平支持“NG 检出率至少 90%”，举例：100 张独立 NG 中至少 96 张严格检出，Wilson 95% 下界约 90.2%。若希望用零误报支持“OK 误报率低于 1%”的一侧 95% 上界，约需 299 张独立 OK 且零误报。样本应来自多个批次，不应只取相邻帧。
4. 在完成独立测试前，`0.25` 是当前 V6 默认 Python 分支的**验证集**候选阈值；免 NMS 分支需独立选阈值。上线前还要按产线每小时图片量核算误报次数和人工复核负担。

下一轮收到同工况数据后，按下表继续迭代。每轮固定训练/验证清单、候选阈值和预处理；只在训练侧补图或改配置，最终独立测试图始终不参与选择。

| 观察到的失败类型 | 首先核对什么 | 对应训练动作 | 复核指标 |
| --- | --- | --- | --- |
| NG 完全没有候选框 | 标注是否真实打结、目标是否被裁掉、尺度是否低于有效特征层 | 补同类贴边/短突起图；必要时提高有效裁图分辨率 | 同类 NG 的 IoU≥0.5 检出数，推理耗时 |
| NG 有高分框但 IoU 不足 | “核心、连接段、尾带”框范围是否一致 | 先统一标注规则，再试框回归权重与目标尺度 | 严格 IoU 漏检、定位偏差分布 |
| NG 有正确框但分数低 | 光照/材料/正常耳带形态是否与训练分布不同 | 增加真实工况样本，针对性调亮度增强与采样比例 | 固定阈值下 NG 检出及亮度分层结果 |
| OK 被误报 | 是否是正常交叉、裁切边界、印字或材质纹理 | 采对应硬负例；避免只靠降低阈值 | 每千张 OK 误报数与每小时复核量 |

每轮先更新逐图错误清单，再选择一项变化训练；若 NG 检出上升但 OK 误报或多余框同步变差，保留两种模型作候选，不只按 mAP 选一个。独立验收需多批次图像，且同批次同时有 OK/NG，才能检验当前数据的日期与亮度捷径是否被打破。

### 最后一张严格 IoU 漏检与特征分析

V4 在阈值 0.03 下唯一未达到 IoU 0.5 的 NG 是 `C1_260313_15h57m53s193ms_dajie.bmp`。模型在该位置输出 **0.489** 的高分框，但框偏右且偏短，与标注 IoU **0.419**；存在 0.0038 的低分框可达 IoU ≥0.5。因此这张属于**定位范围不足**，不是完全没有找到图像里的异常。若只按“图上是否报 NG”计，它会被报出；但为缺陷提取仍按严格 IoU 记漏检。

关键层热图显示，早期卷积已响应耳带轮廓，backbone P3/P4 在标注区域有明显响应，neck P3 的局部能量与整个图接近。不能说“特征没有提取”；更值得检查标注框是否统一包含耳带末端及下方连接段，以及检测头是否只框住最显著的突起。V4 对 29 张验证 NG 做了“模糊标注区 vs 模糊镜像位置”的扰动检查：26/29 张的目标区域扰动使匹配分数下降得更多，中位下降约 0.200，而对照区域中位下降约 0.0004。此试验是关联性诊断，模糊本身也可能造成人工边缘；上述唯一严格漏检图在模糊目标后分数反而从 0.004 升至 0.033，提示局部纹理/框尺寸的脆弱性，不能当作正确提取的证据。

下一步先试提高框回归损失权重，再试适中分辨率训练；每次保持同一训练/验证清单并逐图复核。后续应补充同日同机位 OK，以及“打结末端长度”和“框住核心或全部尾带”的统一标注准则。

V6 在 0.25 阈值下将严格检出提高到 28/29，唯一未匹配图改为 `C1_260313_15h57m56s219ms_dajie.bmp`：下方耳带末端贴近图像边界；有 0.390 高分框，但该框不与标注达到 IoU 0.5，正确重叠框只有 0.0098。提高框损失帮助了上一张定位不足图，却未稳定覆盖贴边形态。V7 改用 800 输入训练/推理后，0.25 阈值回落为 27/29；降到 0.10 可达 28/29、OK 0/5，但输入更大，未优于 V6。仅把 V6 推理尺寸改到 800，在 0.25 阈值仍是 28/29，却出现 1/5 OK 误报。因此保留 640 作为当前候选输入尺寸。

V14 对这张贴边图的早期卷积、backbone P3/P4 和 neck P3 热图也显示标注附近有响应，尤其沿垂带和白色虚线；边框、印字及正常耳带同样强烈响应。结合逐框分数，不能将“有热区”等同于模型已区分打结核心。局部放大与多层特征见可视化 HTML；原始图在 `features/v14_box15/C1_260313_15h57m56s219ms_dajie_summary.jpg`。

修正为真实推理补边后，这张图的 V6 标注区/全图平均激活比在早期层、P3、P4、neck P3 分别为 1.119、1.105、1.078、1.028；V14 分别为 1.119、1.102、1.050、0.999。两者没有出现可单凭平均激活判定的显著差别，真正影响输出的是通道组合、定位和检测头分数，故还需结合遮挡与逐框结果。
